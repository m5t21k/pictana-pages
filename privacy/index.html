プライバシーポリシー

対象：Pictana iOSアプリ ／ 発効日：2026年11月23日

Pictanaは、利用者のプライバシーを尊重し、スクリーンショットを整理するために必要な範囲で情報を取り扱います。本ポリシーは、アプリ、サポート窓口、および本サイトにおける情報の取扱いを説明します。

アプリが扱う情報と利用目的

写真ライブラリとスクリーンショット

利用者が許可した写真ライブラリ内のスクリーンショットを読み取り、サムネイル表示、文字認識、分類、タイトル・要約・予定・場所・商品・タスク情報の抽出に利用します。写真アプリの元画像を自動的に削除することはありません。限定アクセスを選んだ場合は、利用者が選択した写真だけを扱います。

端末内解析と保存

Vision OCR、ルール解析、および対応端末のApple Intelligenceを利用した解析は端末内で行います。カード、OCR本文、メモ、分類の手直し、抽出した日時・住所・価格・リンク、解析履歴、設定値はアプリの端末保存領域に保持します。端末内解析だけを利用している間、スクリーンショット画像とOCR本文をPictanaの運営者サーバーへ送信しません。

クラウドAI解析（Firebase / OpenAI）

クラウド解析は初期状態でオフです。利用者が設定で有効にし、外部送信の説明に同意した場合だけ、スクリーンショット画像、OCR本文、および端末内解析の暫定結果をFirebase Cloud Functions経由でOpenAI APIへ送信します。分類、タイトル、要約、日時、場所、価格、リンク、タスク候補を生成する目的にのみ使用します。通信や解析に失敗した場合は端末内解析の結果へ戻ります。

Firebase Cloud Functionsは画像、OCR本文、解析結果をFirestoreへ保存しません。OpenAI APIへのリクエストでは、応答をモデル改善用に保存しない設定を指定します。OpenAIにおける処理や保持は、契約・安全対策・適用法令およびOpenAIのプライバシーポリシーに従います。利用者は設定からクラウド解析をいつでもオフにできます。

匿名認証、利用枠、不正利用防止（Firebase）

クラウド解析の利用枠管理と不正利用防止のため、Firebase Authenticationでパスワードやメールアドレスを伴わない匿名アカウントを自動生成します。Firestoreには、匿名IDを一方向ハッシュ化した識別子、解析利用回数、処理中・完了済みリクエストの識別子、更新日時を保存します。スクリーンショット画像、OCR本文、解析結果はこの利用枠記録に保存しません。

Firebase App Checkは、正規のPictanaアプリからのリクエストであることを確認するため、アプリ・端末の検証トークン等を処理します。Firebaseにおける情報の処理についてはFirebaseのプライバシーとセキュリティをご確認ください。

広告・同意管理（Google Mobile Ads / UMP）

無料版ではGoogle Mobile Ads SDKを利用し、バナー広告または利用者が自ら選択して視聴するリワード広告を表示します。地域や法令に応じた同意確認のため、Google User Messaging Platform（UMP）を利用します。広告の読み込みは必要な同意状態を確認してから行います。

Pictanaは、スクリーンショット画像、OCR本文、検索語、カード内容、住所、予定、価格、分類結果を広告SDKへ渡さず、広告リクエストのキーワードやカスタムターゲティングにも利用しません。初回リリースではパーソナライズ広告を前提とせず、他社のアプリやウェブサイトをまたぐトラッキングの許可を要求しません。

Google Mobile Ads SDKは、広告配信、効果測定、不正防止、サービス改善等のため、IPアドレスから推定されるおおよその位置情報、端末またはアプリ識別子、広告データ、製品・広告操作、クラッシュログ、パフォーマンス・診断情報等を処理する場合があります。実際の処理は地域、端末設定、同意状態、広告設定等によって異なります。詳しくはGoogle Mobile Adsのデータ開示、UMPの説明、Googleプライバシーポリシーをご確認ください。

Pictana PlusまたはPictana AI Proの権利が有効な場合、アプリは広告をリクエストしません。広告プライバシー設定の再表示が必要な地域では、アプリ内の設定から選択内容を確認・変更できます。

購入（StoreKit 2）

アプリ内購入はApple StoreKit 2を利用します。支払い方法やカード情報はAppleが処理し、Pictanaは取得しません。アプリは商品IDと検証済み取引の権利状態を確認し、広告表示、買い切り機能、サブスクリプション機能を制御します。購入、返金、請求、解約はApple Accountで管理されます。

外部アプリ・サービスへの移動

利用者の操作により、予定をAppleカレンダーの編集画面へ渡したり、場所を地図で検索したり、商品や出典のウェブページをSafari等で開いたりできます。移動先のサービスでは、各事業者のプライバシーポリシーが適用されます。Pictanaが確認なしに予定を保存したり、外部ページを開いたりすることはありません。

お問い合わせで受け取る情報

サポート窓口へメールを送信した場合、メールアドレス、本文、および利用者が任意で記載した端末・OS・アプリ情報を、回答と問題調査のために利用します。問い合わせに不要なスクリーンショット、OCR本文、住所、予定、購入情報等は送らないでください。

保存期間と削除

端末内のカード、OCR本文、メモ、解析結果、設定は、利用者がアプリ内で削除するか、アプリを削除するまで保持します。「すべてのアプリ内データを削除」を実行しても、写真アプリの元画像とAppleが管理する購入権利は削除されません。

クラウド解析用の匿名アカウントと、関連する利用回数情報は、アプリ内の削除機能から削除を開始できるようにします。削除後は元に戻せません。サポートメールは回答、問題調査、対応記録に必要な期間保持し、その後削除します。法令上の義務または紛争対応のため保持が必要な場合を除き、利用者はお問い合わせ先へ自身が送信したサポートメールの削除を依頼できます。

許可と選択の変更

写真アクセスはiPhoneの「設定」から変更できます。クラウド解析はPictanaの設定からオフにできます。広告同意の選択肢が提供される地域では、アプリ内の広告プライバシー設定から変更できます。権限や同意を拒否・変更すると、写真の取り込み、クラウド解析、広告による追加枠など一部機能を利用できない場合がありますが、保存済みカードの閲覧や端末内で利用できる機能は可能な範囲で引き続き提供します。
